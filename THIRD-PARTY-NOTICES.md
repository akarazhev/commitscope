# Third-party components

This source distribution contains original orchestration code, prompts, baseline
rules, synthetic application fixtures, and documentation. It does not redistribute
Semgrep, Gitleaks, Trivy, Claude Code, vulnerability databases, Python dependencies,
or GitHub action source code.

The installer retrieves third-party releases whose license/terms remain those of their
respective authors and publishers. Review those licenses and any database/API terms
before organizational deployment. The project's own license does not relicense any
downloaded component, hosted service, or vulnerability dataset.

The example's fake token is not a real credential. Its vulnerable requirements file
is inert scanner input and must not be installed. Example findings are not claims
about a real customer application.

See `docs/SOURCES.md` and `config/tools.lock.json` for upstream locations and selected
artifact digests. No affiliation with or endorsement by the tool vendors is implied.
